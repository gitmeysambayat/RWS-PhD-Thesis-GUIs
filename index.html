From analysis to usable software

The workflow behind the tools

01

Generate and organise

My PhD workflow uses Python and Abaqus for a parametric study of circular reduced web section connections. The published tools organise the resulting response data by geometry and steel grade.

02

Compare and interpret

Interactive curves, contour images and screening plots make it possible to examine trends and individual cases, with the underlying assumptions kept visible.

03

Predict and communicate

An exported machine-learning model brings backbone prediction into the browser, alongside FE comparisons, documentation and links to the research.

These are research exploration tools for the studied RWS connections. Their database checks and predictions need to be interpreted within the documented assumptions and limitations.
