Quick start

Use IPE270, S235 and span-to-depth 6. Compare C00 (diameter/depth 30%, distance/depth 60%) with C100 (full section).

  1. Reduced Web Section Beams Explorer. Choose C00, click Add curve, then Select C100 (Full section) to overlay the two backbones.
  2. Dynamic Radar Plot. Filter to the same profile, grade and span setting. Adjust the response ranges and Top N to rank the remaining cases.
  3. Cumulative Energy Dissipation. Choose the matching batch. Click Clear all, select C00 and C100, then Plot selected. Switch to normalised energy for a relative comparison.
  4. FE and ML Backbone Prediction. Select C00 in FE mode, then switch to ML prediction mode. Try a geometry between FE settings to obtain a predicted backbone.

How the tools work

FE explorer

Displays stored backbones and von Mises/equivalent plastic strain (PEEQ) contours. Plots export as SVG; the browser does not run Abaqus.

Radar ranking

Uses six response indicators with fixed global normalisation. Outward denotes the selected favourable direction. Polygon-area rankings depend on scales and spoke order.

Cumulative energy

Plots saved cumulative energy in kJ or normalised by the full-section value at each cycle. Compare cases with the same loading sequence.

ML prediction

Runs 400 exported XGBoost trees in the browser. Nine features yield 21 normalised moment ordinates, scaled by section plastic moment. The database benchmark compares predictions with stored FE backbones.
