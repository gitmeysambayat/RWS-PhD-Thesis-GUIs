PhD thesis: Predicting Reduced Web Section (RWS) Connection Performance with Circular Web Opening in Steel Moment Frames.

I used Python and Abaqus for the parametric study and developed these browser tools to compare results and run XGBoost predictions.

Supervisor: Professor Konstantinos Daniel Tsavdaridis.
